# LEARN.md — "what I learned" (plain words, max 5 lines per phase)

- **Phase 0:** In `src/` layout the pyproject `name` (`sowl`) is the distribution name, NOT the import name — hatchling builds an empty wheel unless told `[tool.hatch.build.targets.wheel] packages = ["src/ag"]`. `uv sync` installs your own project editable into `.venv`, which is why `import ag` just works in tests. `uv.lock` pins exact versions; commit it (apps, unlike libraries). TDD even works for scaffolding: wrote the import test first, watched all 13 fail with exactly `ModuleNotFoundError`, then made them pass.
- **Phase 1:** Sockets are two-way byte pipes between programs; Unix Domain Sockets (UDS) use a disk path (`~/.ag/ag.sock`) to transfer bytes purely within kernel memory with zero network overhead and POSIX file security. Streams lack message boundaries, so newline framing (`\n`) tells the receiver where each JSON-RPC 2.0 message ends. Stale socket files survive crashes: test-connect first, and if refused, safely unlink the dead socket. Fast CLI response requires avoiding heavy top-level imports: deferring Typer/Rich kept total `ag ping` process runtime under 30ms (0.1ms pure wire roundtrip).
- **Phase 2:** OpenAI-compatible wire formats unify all LLM backends (Ollama, llama.cpp, cloud) behind a single `POST /v1/chat/completions` HTTP contract, eliminating SDK bloat. Profiles in `profiles/*.yaml` decouple model parameters from agent logic so switching models requires zero code changes. Cross-platform hardware diagnostics via `psutil` and `nvidia-smi` safely determine optimal tiers without crashing on missing drivers. Structured outputs via `response_format json_schema` guarantee responses validate against Pydantic models. Mocking via `httpx.MockTransport` enables instant offline TDD without running live model weights.
- **Phase 3:** Implemented TOON spec 4.4 using official `toon-format==1.2.0`. Measured token counts: `tools.json` dropped from 754 to 381 (49.5% savings vs compact JSON), `snapshot.json` from 697 to 355 (49.1% savings), and `plan.json` from 219 to 217 (0.9% savings) — yielding 42.9% headline savings across 1,670 total tokens. Declared length `[N]` and `finish_reason='length'` catch prompt truncation early. Fences (```json/toon) and surrounding prose are cleanly stripped. Callers are fully isolated via `WireError` and `TruncatedOutputError` with a 1 MB input cap.
- **Phase 4:** Declarative manifests (`manifest.toml`) parsed with `tomllib` and `pydantic` separate tool metadata from execution logic, keeping prompt tokens minimal via compact tables while loading `SKILL.md` instructions only on demand. Enforcing handlers strictly from `ag.skills.builtin.*` prevents arbitrary code execution when discovering skills across packages and workspace directories. Strict filesystem boundaries (`is_relative_to` after symlink resolution) and deny lists (`.env*`, `*.pem`, `id_rsa*`) prevent directory traversal and secret leaks in R0 tools. Pre-execution risk checks guarantee R3 tools never run, while args are strictly validated (`extra="forbid"`) and blocking handlers run inside `asyncio.to_thread` with a 10s timeout. Gmail compose uses web URLs for rich drafts without OAuth/send permissions; `mailto:` remains the universal OS fallback.
- **Phase 5:** Autonomous agent loops require strict prompt ordering (static system prompt and compact tool table first) so modern inference engines maximize prompt prefix KV-cache reuse. OpenAI's `reasoning_effort: "none"` disables internal chain-of-thought bloat when executing structured tool planning, saving hundreds of hidden reasoning tokens. Untrusted observations must be wrapped in unique run delimiters within user/tool messages (never system) to reduce prompt injection surface. Streaming protocols over local Unix domain sockets permit real-time human confirmation gates with cryptographic action hashes to prevent connection hijack. Logging JSONL traces with 0700/0600 file permissions and automatic rolling pruning provides full deterministic auditability with zero credential exposure.
- **Phase 5 (Fixes):** Truncating tabular data rows and strings before serialization ensures TOON declared counts `[N]` remain valid and decodable without errors. Strict KV-cache prefix stability demands zero run-specific delimiters or timestamps in the system message. Audit logging of confirmation requests and decisions with explicit source tracking (`user`, `timeout`, `policy`, `test_runner`) provides accountability for human-in-the-loop actions. Restricting endpoint overrides to loopback addresses ensures agent RPC commands remain local-first and secure by default.
- **Phase 6:** In-process evaluation harnesses eliminate socket/daemon overhead, enabling fast reproducible benchmarking of full agent loops against diverse scenario splits (dev vs blind holdout). Pure-function grounding auditors catch hallucinated parameters by verifying identifier arguments (paths, URLs, emails) strictly against the task prompt and prior tool observations. Sandboxed temp workspaces combined with mock launcher backends prevent accidental network escapes, account mutations, or external browser interactions during automated testing. Setting CUDA_VISIBLE_DEVICES="" and GGML_VK_VISIBLE_DEVICES="" guarantees true CPU-only inference in Ollama, cleanly exposing execution throughput differentials between CPU (4.8 tok/s) and GPU offloading (28.8-58.9 tok/s). Statistical thresholding (net delta <= 3 tasks flagged inconclusive) prevents noisy false-positive model configuration regressions.
- **Phase H:** Serving local web UIs safely requires strict defense-in-depth: validating Host headers prevents DNS rebinding, checking Origin guards against cross-site WebSocket hijacking, and single-use startup tokens in URL fragments exchanged for SameSite=Strict HttpOnly cookies block unauthorized LAN access. Eliminating markdown HTML rendering in favor of textContent alongside stripping ANSI, control, and Unicode BiDi overrides completely neutralizes stored and reflected XSS. Positioning confirmation modals outside the chat DOM guarantees LLM responses cannot visually spoof approval prompts. Validating session IDs against strict hex patterns and bounding conversational context continuation retains multi-turn coherence without filesystem traversal risks or memory bloat.
- **Planner Prompt Fixes & Conversational/Refusal Evals:** Clear prompt rules directing no-tool queries ("what can you do?", "what model are you?") to direct done actions prevent the planner from hallucinating missing tools. Enforcing the refusal prefix "I can't do that yet:" standardizes programmatic verification while banning ask actions for refusals keeps the clarification pathway strictly for missing parameters. In the web UI, rendering ask actions as "Needs your input" and refusals as standard plain messages ensures clear visual demarcation without confusing warnings.
- **Laya Gate, Provenance & Decision Judge:** Tracking taint and data provenance across multi-step execution stops prompt injection cold: untrusted data inside tool outputs is flagged as tainted so the agent cannot silently use injected URLs or emails without human confirmation displaying the origin. Strict identifier normalization (handling case, URL decoding, trailing punctuation, and workspace-relative paths) eliminates grounding auditor false positives. Secondary LLM decision judges (Layer B) must be monotonically strict—they can only upgrade decisions to confirm or block, never loosen deterministic Layer A rules. Verifying post-conditions (like checking created files or query parameters on compose URLs) catches failed tool runs deterministically before returning control. Secure decision logging with 0600 file permissions and sanitized identifier guidance ensures safety auditing without leaking unauthorized parameters back into prompt context.
- **Controlled Browser Automation via CDP:** Attaching Playwright over CDP to a dedicated Chrome profile (`~/.ag/chrome-profile`) isolates automation state completely from default personal browsing while allowing one-time logins to persist. Generating server-side numbered references (`@e1`, `@e2`) from accessibility snapshots avoids injecting brittle DOM attributes; re-verifying element role and text before clicking detects stale references and dynamic layout changes deterministically. Word-boundary escalation patterns reliably catch sensitive operations (send, submit, delete, checkout, pay) and escalate them to R2 human confirmation. Hard engagement guards permanently block interaction features (likes, follows, comments, replies) on social platforms at R3 risk level. Enforcing loopback-only CDP binding (127.0.0.1) and strict URL scheme filtering blocks navigation escapes to local network resources or high-risk protocols.
- **Service Grounding and Autonomous Browser Entry:** Service domain URLs mentioned by name in prompts (e.g. Instagram) or declared in skill recipes must be seeded into the provenance store so security gates don't falsely block them as invented identifiers. Giving web skills strict instructions to open the target site first and inspect page snapshots prevents premature asking and conversational refusal biases.
