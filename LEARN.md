# LEARN.md — "what I learned" (plain words, max 5 lines per phase)

- **Phase 0:** In `src/` layout the pyproject `name` (`sowl`) is the distribution name, NOT the import name — hatchling builds an empty wheel unless told `[tool.hatch.build.targets.wheel] packages = ["src/ag"]`. `uv sync` installs your own project editable into `.venv`, which is why `import ag` just works in tests. `uv.lock` pins exact versions; commit it (apps, unlike libraries). TDD even works for scaffolding: wrote the import test first, watched all 13 fail with exactly `ModuleNotFoundError`, then made them pass.
- **Phase 1:** Sockets are two-way byte pipes between programs; Unix Domain Sockets (UDS) use a disk path (`~/.ag/ag.sock`) to transfer bytes purely within kernel memory with zero network overhead and POSIX file security. Streams lack message boundaries, so newline framing (`\n`) tells the receiver where each JSON-RPC 2.0 message ends. Stale socket files survive crashes: test-connect first, and if refused, safely unlink the dead socket. Fast CLI response requires avoiding heavy top-level imports: deferring Typer/Rich kept total `ag ping` process runtime under 30ms (0.1ms pure wire roundtrip).
- **Phase 2:** OpenAI-compatible wire formats unify all LLM backends (Ollama, llama.cpp, cloud) behind a single `POST /v1/chat/completions` HTTP contract, eliminating SDK bloat. Profiles in `profiles/*.yaml` decouple model parameters from agent logic so switching models requires zero code changes. Cross-platform hardware diagnostics via `psutil` and `nvidia-smi` safely determine optimal tiers without crashing on missing drivers. Structured outputs via `response_format json_schema` guarantee responses validate against Pydantic models. Mocking via `httpx.MockTransport` enables instant offline TDD without running live model weights.
- **Phase 3:** Implemented TOON spec 4.4 using official `toon-format==1.2.0`. Measured token counts: `tools.json` dropped from 754 to 381 (49.5% savings vs compact JSON), `snapshot.json` from 697 to 355 (49.1% savings), and `plan.json` from 219 to 217 (0.9% savings) — yielding 42.9% headline savings across 1,670 total tokens. Declared length `[N]` and `finish_reason='length'` catch prompt truncation early. Fences (```json/toon) and surrounding prose are cleanly stripped. Callers are fully isolated via `WireError` and `TruncatedOutputError` with a 1 MB input cap.
- **Phase 4:** Declarative manifests (`manifest.toml`) parsed with `tomllib` and `pydantic` separate tool metadata from execution logic, keeping prompt tokens minimal via compact tables while loading `SKILL.md` instructions only on demand. Enforcing handlers strictly from `ag.skills.builtin.*` prevents arbitrary code execution when discovering skills across packages and workspace directories. Strict filesystem boundaries (`is_relative_to` after symlink resolution) and deny lists (`.env*`, `*.pem`, `id_rsa*`) prevent directory traversal and secret leaks in R0 tools. Pre-execution risk checks guarantee R3 tools never run, while args are strictly validated (`extra="forbid"`) and blocking handlers run inside `asyncio.to_thread` with a 10s timeout. Gmail compose uses web URLs for rich drafts without OAuth/send permissions; `mailto:` remains the universal OS fallback.
